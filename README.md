# Residenza Verdi8 — GitHub Pages

## Deploy
1. Crea repository pubblico GitHub
2. Carica tutti i file nella root
3. Settings → Pages → Branch: main → / (root)

## Struttura
- index.html — Homepage
- app-a.html — Appartamento A
- app-b.html — Appartamento B
- villa-c.html — Villa C
- attico.html — Attico
